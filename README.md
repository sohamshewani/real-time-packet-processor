## Real-Time Packet Processor

A Java-based CLI utility for real-time, zero-copy network packet processing, designed for high-performance streaming data handling.

### Files
- `src/main/java/com/example/packet/Processor.java`
- `src/main/java/com/example/packet/Packet.java`
- `src/main/java/com/example/packet/NetworkInterface.java`
- `src/main/resources/config.properties`
- `build/run.sh`
- `pom.xml`

### Build and Test Command
```bash
mvn clean install && ./build/run.sh
test.sh
```
